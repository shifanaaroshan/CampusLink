# 🎓 Campus Link

Campus Link is a student resource sharing platform designed to help students and faculty collaborate by sharing academic resources, experiences, and knowledge within a college campus.

---

# 🌟 Features

- 👤 Student & Faculty Login
- 📚 Share Notes
- 📽 Upload PPT Presentations
- 🎧 Upload Audio Resources
- 💼 Share Placement & Internship Experiences
- 🔍 Smart Resource Search
- ❤️ Save Favourite Resources
- 🏆 Recognition & Awards
- 📊 Contribution Statistics
- 👩‍🏫 Faculty Resource Section
- 👤 Student Profile
- 🌙 Dark Theme
- 🔔 Notifications
- ⚙ Settings

# 🎯 Purpose

Campus Link aims to encourage knowledge sharing among students and faculty by creating a centralized academic resource platform.

Students can:

- Upload useful study materials
- Access resources shared by others
- Learn from faculty
- Build their academic profile
- Earn recognition for meaningful contributions
